# Account Deletion --- 21

**Developer:** Brlek\
**Privacy contact:** brkibb@gmail.com

## How to request deletion

Users can request deletion of their 21 account and associated personal
data:

1.  Open 21.
2.  Go to **Settings → Account → Delete Account**.
3.  Confirm the deletion request.
4.  Follow the confirmation steps shown by the App.

A web-based deletion page will also be provided so a user who has
uninstalled 21 can request deletion without reinstalling the App.

The web deletion page must clearly identify the App as **21** and the
developer as **Brlek**.

## Data deleted

Where applicable, account deletion will remove or anonymize: - Account
identifier - Email/account authentication association - Username
association - Personal profile/account data - Match history associated
with the account - Personal leaderboard association - Reroll usage
associated with the account - Premium account entitlement association,
subject to purchase-platform records and legitimate retention
requirements

## Data that may be retained

Certain information may need to be retained for legitimate reasons,
including: - Fraud and abuse prevention - Security investigations -
Legal obligations - Financial/transaction records

Any retained information should be minimized and retained only as long
as necessary.

## Premium purchases

Deleting an account does not automatically create a refund or cancel a
platform purchase. Users should use the applicable Google Play
purchase/refund mechanisms where required.

If a Premium entitlement is tied to a deleted account, restoration and
account recovery may be affected. The deletion confirmation should
clearly warn the user before final deletion.

## Implementation requirement

The deletion process must actually delete associated personal data.
Freezing or disabling an account alone is not sufficient.

Google Play requires an in-app deletion path and an external web
resource for apps that allow account creation. The web resource must
provide a functional way to request account deletion.
