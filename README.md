# 21 — GitHub Pages

This folder is a small public policy/support site for the 21 game.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `21-legal`.
2. Upload all files in this folder to the repository root.
3. In GitHub open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide a public URL such as:
   `https://YOUR-USERNAME.github.io/21-legal/`

Use the resulting URL in Google Play Console.

The Privacy Policy URL should point directly to:
`https://YOUR-USERNAME.github.io/21-legal/privacy-policy.html`

The account deletion URL should point directly to:
`https://YOUR-USERNAME.github.io/21-legal/account-deletion.html`

## Important

The internal `SECURITY_POLICY.md` and `PLAY_CONSOLE_CHECKLIST.md` are intentionally NOT included in the public site. Keep those private.
